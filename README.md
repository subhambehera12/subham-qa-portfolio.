# Subham Behera — QA Automation Portfolio

A responsive static portfolio website inspired by the reference at https://sdebasis0709.github.io/portfolios/ and customized using the supplied resume.

## Files
- `index.html` — content and sections
- `styles.css` — responsive styling and visual theme
- `script.js` — mobile navigation and active section highlighting

## Preview locally
Open `index.html` in a browser. Internet is only needed to load the Google Fonts; system fallbacks are included.

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `subham-qa-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the published URL shown in the Pages settings.

## Before publishing
- Confirm that the 4.3 years experience statement and dates are accurate.
- Check whether you want your email displayed publicly.
- Add your LinkedIn, GitHub, and a downloadable resume link if desired.
- Confirm you are allowed to describe the named client projects publicly.
- This portfolio does not claim unverified performance metrics or include private source code.
